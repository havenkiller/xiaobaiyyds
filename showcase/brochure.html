关于小白

小白是你的专属 全能任务处理中枢
—— 一个框架无关的超级智能体。
它不是一个普通工具，而是一个完整的 AI 智能体生态系统。启动时自动扫描所有可用 skill， 建立「任务类型 → 适用 skill」的映射索引。面对复杂任务，它能自动分解、规划并调用 最适合的工具链，甚至组建多智能体团队并行工作。每次任务完成后还会记录笔记， 下次相遇时它还记得你和它的每一次对话。

应用场景

🚀

新项目启动

「我想做一个 SaaS 后台管理系统」

小白启动 office-hours 头脑风暴 → 生成设计文档 → 规划技术方案 → 分配任务给前端+后端智能体并行开发 → 测试 → 部署。从 idea 到上线，全流程护航。

效果：原来需要一周的启动工作，缩短到几小时。
🐛

紧急 Bug 修复

「线上登录按钮点了没反应」

小白启动 investigate 系统化排查：检查日志 → 复现问题 → 分析根因 → 定位到 JS 事件绑定错误 → 修复 → 验证。

效果：5 分钟定位根因，2 分钟修复上线。
📄

文档与报告生成

「把这份需求文档做成 PPT」

小白读取需求内容 → 调用 pptx skill 智能排版 → 选择合适的主题配色 → 生成专业级幻灯片。Word、Excel、PDF 同理。

效果：从空白到成品 PPT，不到 1 分钟。
🎨

品牌设计

「帮我设计一套品牌视觉系统」

小白调用 design-consultation → 研究行业竞品 → 设计配色、字体、间距系统 → 生成 DESIGN.md 设计源文档。

效果：专业级设计系统，包含完整的设计 token。
🔬

技术调研

「对比 React 19 和 Vue 4 的优劣」

小白联网搜索最新信息 → 抓取官方文档 → 对比性能/生态/学习曲线 → 输出结构化对比报告。

效果：全面且客观的调研报告，附带来源引用。
