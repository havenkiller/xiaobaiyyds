# xiaobaiyyds — 超级智能助手

> 全能任务处理中枢 · 框架无关 · 多智能体专家团协作

## 一句话

**小白 yyds** 是你的专属 AI 任务管家。它自动掌握你 skill 库里全部能力，面对任何任务都能智能匹配最合适的 skill 来执行。复杂任务还能启动专家团模式——像一整个产品团队帮你干活。

## 使用方式

在 Claude Code 中输入 `/xiaobaiyyds` 或直接说：

- "小白，帮我做个海报"
- "呼叫小白，调研一下这个技术方案"
- "帮我完成这个任务"

## 核心能力

- **全库精通** — 自动扫描并彻底掌握所有已安装 skill
- **智能路由** — 根据任务类型自动匹配最合适的 skill
- **专家团协作** — 复杂任务拆解为多角色并行工作流
- **持久记忆** — 跨会话记住交互记录、决策、偏好、踩过的坑
- **自动保存** — 完成任务/发现偏好/做出决策时自动保存到项目记忆

## 进阶使用技巧

### 1. 召唤小白

对话前输入以下任意一种方式召唤小白：

```
呼叫小白
/xiaobaiyyds
```

召唤出来后，再发指令让它干活。

### 2. 网络搜索

让小白搜索时，指定它进行**深度、全面**的搜索：

> 明确告诉小白使用搜索 MCP 服务或 CLI 服务效果最佳，或者用搜索 skill 平替。搜完后让小白用 Playwright 验证网站或信息是否真实有效，防止出现打不开的网页。

### 3. 自定义工作流（专家团模式）

需要小白用一套"专业"工作流完成复杂项目时，可以自定义公司/部门工作流：

> **前提**：已安装能全面解决你问题的所有 skill，否则效果大打折扣。AI 大模型的级别也会影响效果，建议用好模型。

召唤指令模板：

```
呼叫小白 /xiaobaiyyds
请你构建一个xx部门（这里自定义）来解决我下面的需求任务，
构建出各个 agent 部门员工进行合理的统管与分工；
但是这些员工目前还没搭配好合适的技能，技术还不过关，
因此，你需要审阅所有的 skill，看看哪些 skill 可以被使用到，
将这些 skill 交给这些员工掌握。
先请你对这个部门进行规划和构建，
因为我之后要以 CEO 的形式发布任务下去让他们去执行！
请你思考，然后执行

任务：xxxxx
```

### 4. 记忆系统

小白有**持久记忆功能**，跨会话记住交互记录、决策、偏好和踩过的坑。

- **自动存档**：每次任务完成后跟小白说"问题解决了""可以了""成功了"之类的答复，小白会自动记下本次过程
- **踩坑记忆**：如果踩了坑，小白会记住，以后绝不再犯
- **如果新项目没有自动开启记忆**，提醒小白"开启记忆存档"
- **记忆归档**：200 条或 60 天自动归档一次，归档的记忆被另外封存，没有你的命令不会去读取
- **上下文安全**：平时小白只加载最近 5 条记忆来回顾上文，不会全盘扫描

### 5. 提升决策质量

做复杂任务时，想让小白的决策更加准确，学会让小白**先思考再执行**：

```
❌ 小白，帮我……
✅ 小白，帮我……，并请你仔细思考，然后规划好方案
```

等方案输出后再执行，效果会大大提升。

### 6. 万能指令模板

如果遇到小白没按预期工作，可以用以下万能指令唤醒完整工作流：

```
请你先务必阅读完我的全部项目内容，
彻底掌握我的全部项目框架，
彻底理解并且精通我的所有功能的使用和布局的内容，
完全熟悉我的全部功能的逻辑后，完成我的任务

你在阅读完所有 skill 和 gstack 框架的相关内容后，
/using-superpowers 自动使用适合我需求的 skill 来继续完成任务，
你可以使用任何 skill 来帮助自己更好地完成任务

如果你需要网络搜索，你可以使用搜索 skills、minimax web search，
且必须是深度搜索，不能只是表面预览，
需要深度搜索全网（国内+国外各大搜索引擎和网站），
并且可以通过 playwright 新开一个浏览器来辅助进行验证
如果需要识图，使用 minimax 识图查看图片内容

1. 先掌握 rule-CLAUDE.md
2. 头脑风暴后规划好所有内容并按照规划一步一步实现 /brainstorming
3. 不明白的需求或者需要补充的内容随时和我进行互动提问来获取答案，
   遇到不明白的事情需要我提供信息或者拿不定主意的时候请及时向我发起询问，
   不要擅作主张
   （开始循环任务执行，完成一个任务需求后使用 askQuestions 工具
    弹出可与用户进行交互的 AQ 对话框询问我下一个任务，
    直到我输出【结束】关键字才算彻底结束）
4. 你需要彻底理解我的需求，对于复杂问题你可以也可以用并行智能体的 skill 进行工作，
   我需要你如同一个专家团 team 协作一样严格的完成一整套工作流
任务：
从现在开始 /autoplan 请你理解我的意思，规划好后继续完成任务
```
